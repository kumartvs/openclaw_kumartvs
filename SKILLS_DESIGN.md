# Skills design

Written and committed before any skill implementation.

## Skill 1: calendar-brief

1. **Problem / when to use**
   Pull real Google Calendar events so Kumar can see the day without opening Calendar. Use when the user says pull calendar, what's on today, schedule, or daily brief.

2. **Tools and five files**
   - Composio Google Calendar (read). Default calendar from TOOLS.md (`primary`).
   - IDENTITY.md: sign the brief as KumarClaw 🦞
   - SOUL.md: short tone; do not invent events
   - AGENTS.md: ask before any Calendar write
   - USER.md: frame events around current OpenClaw work

3. **Success / stop-and-ask**
   Success: a list of real events (time + title) for the requested day from Composio Calendar.
   Stop and ask before creating or changing events.

## Skill 2: docs-pull

1. **Problem / when to use**
   Pull a Google Doc and summarize it. Use when the user says pull doc, read the doc, or summarize my Google Doc.

2. **Tools and five files**
   - Composio Google Docs (read). Default doc from TOOLS.md.
   - IDENTITY.md: KumarClaw 🦞
   - SOUL.md: no invented document text
   - AGENTS.md: ask before editing a Doc
   - USER.md: summarize in the context of current projects

3. **Success / stop-and-ask**
   Success: real Doc title plus a short summary of actual content from Composio Docs.
   Stop and ask before creating or editing a Doc.
